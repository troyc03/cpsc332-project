# Presentation outline (10-15 minutes)

Adapt this outline to the team's tested results. Suggested 10 slides, about 1 minute each, plus a live demo.

1. Title, team members, and problem framing.
2. Original World database overview and its three base tables.
3. Investigation goals and why the indicators were selected.
4. ER diagram: new tables, country-year keys, relationships.
5. Physical model: constraints and data types.
6. Data sources, sample-vs-real data disclosure, temporal mismatch limitation.
7. JOIN query examples and one meaningful result.
8. Subquery examples and one meaningful result.
9. Key findings, caveats, and database demonstration.
10. Conclusions, challenges, and next steps.

Demo: show schema and run one join query plus one subquery query, using validated outputs. Every team member should speak and be present per course instructions. Do not show synthetic values as official statistics.
